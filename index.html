01

Profile

I work at the point where a deployment either lands cleanly or takes subscriber service down with it. At Rakuten Mobile, that means commissioning Nokia SDM network elements, wiring them into the wider 5G and IMS core, and then proving the result — configuration checks, interface validation, SIT/UAT and post-deployment service verification.

My core is subscriber data: HSS, NT HLR, UDM, AUSF, SDL, EIR, One-NDS and Oracle PCRF, surrounded by the IMS and EPC fabric of AMF, NRF, SMF, UPF, PCF, MME, DRA, STP, SBC, P-CSCF, S-CSCF, I-CSCF and TAS. I deploy those functions as Helm-managed containers on Kubernetes and validate them at the pod, interface and service level.

Deployment discipline: install to procedure, integrate to the interface, validate to the subscriber experience, and hand over with documentation the next engineer can act on.

Deployment, integration & commissioning

  • Deploy, configure and commission Nokia SDM network elements (HSS, HLR, UDM, AUSF, SDL, EIR) from installation and node configuration through service activation and deployment sign-off.
  • Deploy 5G UDM cloud-native network functions with Helm charts on Kubernetes — chart configuration, installation, upgrade, and validation of pods, services and application status using kubectl.
  • Integrate SDM with HSS/UDM/AUSF, PCRF/PCF, MME, AMF, NRF and IMS core elements (P-CSCF, S-CSCF, I-CSCF, TAS), validating Diameter and SIP interfaces end to end after every integration.
  • Configure subscriber data schemas, service policies and authentication parameters for LTE, VoLTE and 5G subscriber profiles; create users and groups in Keycloak for secret provisioning.
  • Perform subscriber database synchronisation and data migration between Kubernetes-hosted SDM pods, verifying record counts, replication status and data integrity before service release.

Deployment testing & validation

  • Execute SIT and UAT for SDM deployments covering subscriber provisioning, authentication, registration, mobility and roaming scenarios; record results in test and acceptance reports.
  • Validate Diameter interfaces and subscriber provisioning flows using protocol traces, transaction logs and PCAP captures to confirm correct request/response behaviour before sign-off.
  • Validate 5G registration, authentication, PDU session establishment and deregistration, plus LTE data and VoLTE call setup, end to end after each deployment and upgrade.
  • Perform ATP, pre-deployment checks and post-deployment service validation to confirm node health, service status and KPI compliance at handover.

Upgrades, migration & documentation

  • Execute software upgrades, patch and Helm chart deployments for Nokia/Mavenir CFX alongside vendor and L2/L3 teams, including pre-upgrade backup, rollback planning and post-upgrade validation.
  • Prepare MOP/RMOP, LLD/HLD inputs, test reports, deployment reports and handover documentation, and coordinate with vendors and L2/L3 teams during deployment windows.

How a deployment runs

  1. 01

    Provision

    Install and commission the node, apply subscriber data schemas, service policies and authentication parameters.

    install · configure · schema

  2. 02

    Integrate

    Wire SDM into HSS/UDM/AUSF, PCRF/PCF, AMF and the IMS core, then prove the Diameter and SIP interfaces.

    diameter · sip · interfaces

  3. 03

    Validate

    Run SIT and UAT against real subscriber flows — registration, authentication, PDU session, VoLTE call setup.

    sit · uat · atp

  4. 04

    Hand over

    Patch and upgrade to procedure, confirm service, and close with MOP, test and deployment documentation.

    upgrade · report · handover
